# Digital Gnosis Facelift

Deployable frontend redesign for Digital Gnosis.

## Stack

- React 18
- TypeScript
- Vite 6
- Three.js / React Three Fiber
- Space Grotesk + Inter
- Lucide icons

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Vercel

The repository includes `vercel.json`; import the repo into Vercel and use the default Vite settings. Build output is `dist`.

## Current concept

The hero is built around the Digital Gnosis visual language of **materialization**: an evolving blueprint continuously changes form as new ideas arrive, while part of the geometry resolves into a finished state.

Current procedural forms include a motorcycle, drone, mobile device, architecture, and a network/system form. No external 3D assets are required for the first pass.
